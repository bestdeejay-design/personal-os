## 2. Фазы развития

### Фаза A — Календарь и канбан

| # | Задача | Где | Сложность |
|---|--------|-----|-----------|
| A1 | Создание своих событий в календаре (кнопка «+», форма) | Calendar.tsx | Средняя |
| A2 | Drag-n-drop в недельной сетке | Calendar.tsx (WeekView) | Высокая |
| A3 | Recurring-задачи в канбане | tasks.ts + Kanban.tsx | Высокая |
| A4 | Теги в канбане | tasks.ts + Kanban.tsx | Низкая |

### Фаза B — Шаблоны и поиск

| # | Задача | Сложность |
|---|--------|-----------|
| B1 | Шаблоны заметок (entity Templates, выбор при создании) | Средняя |
| B2 | Шаблоны задач | Средняя |

| B4 | Экспорт всего (ZIP: Markdown + JSON) | Средняя |

### Фаза C — Timeline, Habits, Контакты

| # | Задача | Сложность |

## 4. Рекомендуемый порядок

```
Фаза A (Календарь + канбан)  ─── сейчас, базовый UX
    │
    ▼
Фаза B (Шаблоны + поиск)     ─── ускоряет daily use
    │
    ▼
Фаза D (AI-агент)            ─── киллер-фича
    │
    ▼
Фаза C (Timeline + Habits)   ─── новые разделы
    │
    ▼
Фаза E (Полировка)           ─── доводка
```

TD (техдолг) — вкраплять по 1-2 задачи в каждую фазу.
